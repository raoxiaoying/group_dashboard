集团看板 Quick BI 移动端配置对照

更新日期：2026年10月13日。本次将 Demo 的展示设计限制在 Quick BI 原生组件的可配置范围，供实施人员按组件重建。本文件与 Demo 均不是 Quick BI 可导入模板；尚未登录客户租户完成原生搭建或版本验收。数据仍为模拟数据。

建议样式参数

以下是本 Demo 的设计取值，不是产品默认值：画布 #EDF6FE，组件背景 #FFFFFF，页头 #2452FF（白字），主色 #3370FF，正文 #1F2329，次要文字 #86909C，边框 #E4EBF6；卡片圆角 4px（如版本无圆角配置，使用默认直角），无渐变和卡片投影。页面标题 20px、分区标题 16px、组件标题 14px、指标值 28px、辅助文字 11–12px；卡片内边距 12px，组件间距 8–12px。增减色仅表示方向，不表示成本上升等于经营改善。

报表与参数传递

  1. 首页 → 指标市场页：用指标看板“跳转”，传递指标标识、开始月份、结束月份及查询模式。指标看板不使用钻取。
  2. 市场页 → 门店页：用交叉表跳转传递市场标识，同时保留指标与日期参数；目标页配置对应的接收字段／查询条件。
  3. 可创建每指标独立目标报表；若希望复用统一指标页，则准备长表数据集或参数化指标选择。参数名是实施设计，不是 HTML URL 可以自动转换成 Quick BI 配置。
  4. 在仪表板编辑器切换移动端，解锁独立布局，按分区顺序排列，每行两个指标块。横屏沿用相同组件顺序并放宽容器，优先使用原生图表横屏查看；不依赖横竖屏切换后自动改变组件编排。

数据侧必须配置的内容

  • 保留现有14项指标和来源要求。累计环比为前一等长期间，不能直接假设内置“月环比”就等价；需要在数据集／参数化 SQL 中明确两期边界，汇总后计算。
  • 趋势应使用独立的最近12个月查询范围，不能被“当前单月”筛选截成一个点。当前 Demo 累计模式保留滚动等长区间，原生端需通过日期参数与数据集逻辑实现；确认单中这一规则仍待业务确认。
  • 收入同比按去年同期间；比率指标在集团、市场、门店各级分别汇总基础量后重算。准备本期、上期、去年同期与比较值字段，不用静态格式替代计算。
  • 可比同比仍为明确标注的模拟样本；演示默认2026年9月集团值8.1%。正式可比门店范围、计算公式仍待确认，不把模拟代码直接投产。
  • 翻台率依照已确认的 Σ(日翻台率)/营业天数；营业天数和跨门店汇总规则仍应依确认单确定。

原生验收清单

先在实际租户确认移动端功能与组件版本可用，再验收：320／390／430px竖屏及844×390横屏的无整页横向溢出；首页打开即可见指标数据，14项指标纵向浏览；单月与跨月查询；两级跳转保留期间；12个月标签和点击提示；本期及比较列表头排序；空值与负值；汇总口径；关闭或返回后的查询状态。Demo 的 HTML 自适应验证不能替代 Quick BI 租户、钉钉／企微实际入口的验收。

官方配置依据

  • 搭建移动端报表：移动画布及横向排列组件。
  • 移动端展示：交互支持范围和移动工具提示。
  • 指标看板：主副模板、每行数量及样式。
  • 日期查询与Tab 控件：日期粒度、月区间和筛选范围。
  • 交叉表：移动端排序、汇总和样式。
  • 跳转与标题与卡片：参数化导航和备注。
