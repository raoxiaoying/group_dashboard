集团看板 Quick BI 移动端配置对照

更新日期：2026年10月19日。本次将 Demo 的展示设计限制在 Quick BI 原生组件的可配置范围，供实施人员按组件重建。本文件与 Demo 均不是 Quick BI 可导入模板；尚未登录客户租户完成原生搭建或版本验收。数据仍为模拟数据。

建议样式参数

以下是本 Demo 的设计取值，不是产品默认值：画布 #EDF6FE，组件背景 #FFFFFF，页头 #2452FF（白字），主色 #3370FF，正文 #1F2329，次要文字 #86909C，边框 #E4EBF6；卡片圆角 4px（如版本无圆角配置，使用默认直角），无渐变和卡片投影。页面标题 20px、分区标题 16px、组件标题 14px、指标值 28px、辅助文字 11–12px；卡片内边距 12px，组件间距 8–12px。增减色仅表示方向，不表示成本上升等于经营改善。

报表与参数传递

  1. 首页 → 指标市场页：用指标看板“跳转”，传递指标标识、开始月份、结束月份及查询模式。指标看板不使用钻取。
  2. 市场页 → 门店页：用交叉表跳转传递市场标识，同时保留指标与日期参数；目标页配置对应的接收字段／查询条件。
  3. 可创建每指标独立目标报表；若希望复用统一指标页，则准备长表数据集或参数化指标选择。参数名是实施设计，不是 HTML URL 可以自动转换成 Quick BI 配置。
  4. 在仪表板编辑器切换移动端，解锁独立布局，按分区顺序排列，每行两个指标块。横屏沿用相同组件顺序并放宽容器，优先使用原生图表横屏查看；不依赖横竖屏切换后自动改变组件编排。

管理数据计算口径

毛利率＝（含税收入－含税食材成本）÷含税收入；食材成本率＝含税食材成本÷含税收入；人工成本率＝人工成本÷含税收入；利润率＝实际利润÷含税收入。上述比率乘以100%展示。人工成本沿用工资、社保补贴实发、企业社保和企业公积金合计；实际利润与运营中心利润共用字段。集团、市场及门店均先汇总金额再计算比率。同比＝本期比率－去年同期比率；环比＝本期比率－前一等长期间比率，均按百分点展示。基期不完整时显示“—”。

数据侧必须配置的内容

  • 保留指标计算和来源要求，按新的首页和穿透页结构放置。累计环比为前一等长期间，不能直接假设内置“月环比”就等价；需要在数据集／参数化 SQL 中明确两期边界，汇总后计算。
  • 趋势应使用独立的最近12个月查询范围，不能被“当前单月”筛选截成一个点。当前 Demo 累计模式保留滚动等长区间，原生端需通过日期参数与数据集逻辑实现；确认单中这一规则仍待业务确认。
  • 收入同比按去年同期间；比率指标在集团、市场、门店各级分别汇总基础量后重算。准备本期、上期、去年同期与比较值字段，不用静态格式替代计算。
  • 收入增长率＝（本期除税收入－去年同期除税收入）÷去年同期除税收入；利润增速＝（本期实际利润－去年同期实际利润）÷去年同期实际利润，均乘100%。利润基期为0或缺失显示“—”，负基期按公式保留分母符号；先汇总金额再算增速。
  • 翻台率依照已确认的 Σ(日翻台率)/营业天数；营业天数和跨门店汇总规则仍应依确认单确定。

原生验收清单

先在实际租户确认移动端功能与组件版本可用，再验收：320／390／430px竖屏及844×390横屏的无整页横向溢出；首页打开即可见指标数据，12项指标纵向浏览；单月与跨月查询；两级跳转保留期间；12个月标签和点击提示；本期及比较列表头排序；空值与负值；汇总口径；关闭或返回后的查询状态。Demo 的 HTML 自适应验证不能替代 Quick BI 租户、钉钉／企微实际入口的验收。

官方配置依据

  • 配置查询控件样式：不显示查询按钮时，选择查询条件后自动查询；支持重置。
  • 搭建移动端报表：移动画布及横向排列组件。
  • 移动端展示：交互支持范围和移动工具提示。
  • 指标看板：主副模板、每行数量及样式。
  • 日期查询与Tab 控件：日期粒度、月区间和筛选范围。
  • 交叉表：移动端排序、汇总和样式。
  • 跳转与标题与卡片：参数化导航和备注。

门店数分析

门店数按期末在营统计，按门店ID去重；新开及闭店数按所选期间发生的开业、闭店事件分别去重。闭店月份是最后营业月，月末状态为已闭店。当前门店档案为独立模拟样本：2026年9月末在营499家，东区166家、南区166家、北区167家，共502条档案（含3家已闭店）。历史开业月份为模拟值，同环比及趋势按档案重算；金额、比率仍沿用原财务演示样本，不因门店规模调整而放大。正式门店主数据来源、临时停业及重开规则需确认。三项数量均展示同比、环比，基期为0或缺失时显示“—”。门店数不按月份求和；期间开闭店数量按事件统计。

配置三个指标看板和可切换度量的趋势线图。非年度趋势逐月展示近12个月：在营数取各月末，新开/闭店数取当月发生量；年度趋势按所选年份逐年展示，当前年截至上月。在同一交叉表中分组展示各市场的在营、新开、闭店数量及各自同比环比，支持横向滚动；市场点击进入包含状态、开闭店月份及本期事件的门店明细。

FB-003／FB-004 对比与返回

运营中心收入、成本、人力、利润、排班、人时六项指标在首页、市场对比及门店明细均展示同比、环比。金额用万元、排班出勤率用%、人时成本用元/小时；排班同环比为百分点差，其余为相对变化百分比；返回顺序为门店明细→指标市场页→集团首页，保留查询条件。负责人所辖区域采用用户—市场一对多授权映射；正式系统须在服务端或数据集行级权限中限制可见市场，汇总与穿透均使用授权后的门店集合。当前静态 Demo 已移除负责人范围演示筛选，集团首页展示全部市场，市场穿透仍按所选市场展示。Demo 未接入身份与权限系统，不提供真实权限隔离；实施前需确认负责人、市场映射及维护责任人。

指标卡片同环比采用一行展示，顺序为环比、同比；比率卡片的比较数值后直接显示 pp（百分点），例如 -14.2pp；不另加单位说明行。相对变化使用%。Demo 的 pp 使用 CSS 展示并标注禁止翻译，减少翻译功能将其误译为货币单位的机会。市场与门店表格同样先环比后同比。

门店地图与模块调整

门店数穿透页增加期间净增长（新开数减闭店数）及市场分布地图。地图取所选期间末的在营数量，集团展示三个市场，市场页仅显示对应市场，点击标记保留期间并进入门店明细。底图来自阿里云 DataV GeoAtlas；标记为市场级示意位置，不代表门店真实地址。正式实施需补充门店地理字段并核对所属市场后配置地图。集团会员归入市场营销，营销和人力资源等待需求补充；资金看板保持预留。
